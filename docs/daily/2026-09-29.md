# R4 真机第二天（2026-09-29）总结

**一句话结论**：深度这条线已经解决（FS 在真机上可用，DA 即使按真机内参重训仍偏 −26 mm）。今天换了一种 camera→PSM 标定方法（固定手腕的平移网格），配合相机闭环，把夹爪送到针上方的误差压到 **0.15–0.44 mm**；RL（residual）reach 在真机上跑通。但**两次抓取都没抓起来**：位置是准的，失败原因是**夹爪和针的朝向**（这款夹爪左右张开，要求针身和夹爪轴大致平行）。原计划的 1-b 局部配准两次尝试都失败，原因未查明，已暂停。

完整报告在 `report/SurgicAI_R4_realrobot_20260928.md`（"第二天"章节）；本文件是逻辑梳理和索引。预注册 addendum 在 `results/pre_registration_addendum_day2.json`（sha256 `a6b773a7…`，产生数据前冻结）。标注"未预注册"的部分都是按用户现场要求做的，属于描述性结果。

## 2. 关键结果

### 2.1 深度（图 F1、M1、M2、M3）
- **D7**（flat 场景，24 帧，4 个场景，针约 104 mm；R2 的评估定义）：针区中位偏置 P5a 保持宽高比 −36.1、P5a 方形 −34.6、**EXP8-main −25.9**、EXP8-ctrl −39.7 mm。按真机内参重训只减掉约 1/4–1/3 的偏置。预处理方式的影响只有 1.5 mm。
- **held 场景**（针 70–82 mm，n = 4）：EXP8-main 只有 **−5.3 mm**（P5a −14.1，ctrl −19.3）。偏置随距离增大；这是事后观察，不作判定。
- **0-b 双目 vs ChArUco PnP**：相对误差随 Z 线性变化（b = −0.040 %/mm，CI 不含 0），同时和倾角/画面位置有关（p = 0.015）；两类都成立。校正 P 本身没有错（cx_L = cx_R，B = 5.4476 mm）。原因未定位，不重标定。方格 6.000 mm 已由 R2 卡尺确认，代码里也是 6.0 / 4.0。
- **FS + FP（图 F2）**：FS 单帧和 10 帧均值几乎一样，单帧够用。FP 在 mesh 与针一致时，圆心误差约 1.1–2.1 mm；不一致时完全失败。

### 2.2 camera→PSM 标定（图 F3）
- **0-d**（R2 尖端数据）：Sim(3) 的留出误差并不比 SE(3) 好（比值 1.03，阈值 0.70），所以尺度不是 R2 那 2.8 mm 的主因。
- **1-a**：SUJ 的 `measured_cp` 不随 J0 更新，hand-eye + SUJ 链那 29 mm 偏移**很可能**来自这里（未直接验证）。
- **1-b**：失败，原因未查明。可能的原因（均未验证）：手腕没按指令转（日志里有"跳过啮合流程"）、尖端标注不稳定。已排除：图像滞后（时间戳显示是停稳后拍的）、器械型号配置错误（dVRK 加载的是正确的 ProGrasp 文件）。
- **平移网格标定（今天实际用的）**：仿射留出 RMS 0.52 mm。仿射的奇异值 1.23 / 1.18 / 0.95，说明横向上双目测到的位移比 `measured_cp` 大约 20%；推断是手腕没有抵消机械臂绕 RCM 的转动（未验证），这和 1-b 失败的现象一致。**这个标定只在当时的手腕姿态下有效。**

### 2.3 reach 与抓取（图 F3、F4）
- RL checkpoint：`r6_unified_single_goal_yaw15_seed1_final.zip`（TD3 + HER + BC，150k 步，2026-08-14）。**是否是你重训的版本：未确认**，本机没有更新的 RL 模型。
- 纯 RL 离线就不收敛（这个策略是在"终点要转 25–100° 手腕"的任务上训练的），所以真机只跑了 residual（0.5 × RL + 0.75 × 伺服）：两次都成功到达悬停点。
- 定位误差链：开环 1.62 / 4.47 mm → 相机修正一次 0.20 / 0.15 mm → 闭合夹爪闭环下降 0.44 mm。
- **失败机理（F4 逐帧确认）**：夹爪张开、开环再降 2.5 mm 时针都不动；**闭合时针被推开**。针身和夹爪轴夹角大（57°；抓取 1 约 25°），两片夹爪合拢时从侧面推针，而不是把针夹在中间。另一个可能的因素：高度基准用的是夹爪末端表面上的跟踪点，不是夹爪最低点。

### 2.4 自动分割（图 F5）
- 方法：局部对比度候选 → 去掉宽区域 → RANSAC 找圆（半径按针的尺寸限定）→ 找缝线端，按已知针长截断 → 生成 mask；有 FS 深度时加一道三维检查（R 7.5–10.5 mm，RMS < 0.6 mm）作为置信度。
- 15 个有参考 mask 的场景：**找对针 15/15**（Wilson 95% CI 0.80–1.00）；有深度的 11 个场景里，圆心差中位数 0.62 mm；每张图 0.2–0.6 s。
- 局限：针倾斜时投影是椭圆（被夹着的 held03 偏 2.9 mm，而且没被置信度拦下）；针和缝线的分界依赖已知针长。

## 4. 结论

1. **深度**：FS 可直接用于真机；DA（包括 EXP8）在真机上仍然不可用于米制深度（针约 104 mm 时偏 −26 mm）。
2. **标定**：原有两条路（hand-eye 链、尖端配准）都不可靠；固定手腕的平移网格 + 仿射模型在工作区内能到 0.5 mm，但只对一个手腕姿态有效。
3. **定位**：闭环视觉修正可以把夹爪稳定送到亚毫米位置；开环 1.6–4.5 mm。
4. **抓取**：位置已经不是瓶颈，**瓶颈是夹爪相对针的朝向**，以及闭合瞬间没有反馈。
5. **自动化**：整条流程可以做成纯代码；分割已经自动化并离线验证。
